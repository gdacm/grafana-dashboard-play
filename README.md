# Grafana dashboards play

This repository contains examples usage of the gdacm (Grafana Dashboard as Code Manager) library. The goals of this repository is both to provide practical examples of how to use the library and to verify that some complex diagram examples can be generated correctly.

To do that, this repository tries to recreate some diagrams from https://play.grafana.org/

The diagrams on https://play.grafana.org/ **are not** generated with gdacm, they are maintained by the Grafana team.
